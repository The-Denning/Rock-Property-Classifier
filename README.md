# Rock Property Classifier & Reservoir Quality Dashboard

A live, interactive web application built using Python and Streamlit for petroleum engineering data analysis. This app allows petrophysicists and reservoir engineers to input core sample parameters (porosity, permeability, lithology) to classify reservoir quality, inspect property summary tables, and visualize core samples against reference porosity-permeability trends.

**Live App URL:** *https://rock-property-classifier.streamlit.app/*
